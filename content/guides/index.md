# Guides

Section này tập trung **how-to** — mỗi bài viết là một task cụ thể, có
goal rõ ràng, và kết thúc bằng một check để bạn biết mình đã làm đúng.

Khác với [Reference](/reference) (mô tả *cái gì có sẵn*), guides trả lời
*làm thế nào để đạt được X*. Đọc theo thứ tự nếu bạn mới bắt đầu, hoặc
nhảy tới mục bạn cần.

## Lộ trình đề xuất

1. **[Getting Started](/guides/getting-started)** — cấu trúc thư mục,
   khái niệm content layer, mental model về stacked-column.
2. **[Writing Content](/guides/writing-content)** — frontmatter,
   markdown syntax, tagging, organizing notes.
3. **[Customization](/guides/customization)** — đổi màu, font, override
   component, thêm section vào menu.
