Every page that sets `tags: ["reference"]` in its frontmatter shows up in the list below automatically. This intro is optional: it lives in `content/tags/reference.md` and renders above the auto-collected list. Delete the file and the tag page still works — it just drops the intro and shows the list alone.

Use a tag index like this to turn a bare tag into a real landing page: explain what the tag means, link the canonical starting point — for this tag that's the [Reference](/reference) section — and let the list handle the rest. Any `#tag` chip in the site links here, and clicking a result opens it as the next column in the stack. How tags get onto a page in the first place is covered in [Writing Content](/guides/writing-content).
