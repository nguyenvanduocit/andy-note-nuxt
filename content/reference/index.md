# Reference

Section này **không** dạy bạn làm gì — nó mô tả *cái gì có sẵn*. Dùng
như cheatsheet khi đã đọc qua [Guides](/guides) một lần.

## Mục lục

- **[Frontmatter](/reference/frontmatter)** — toàn bộ field schema, kiểu
  dữ liệu, default, và lúc nào field nào được dùng.
- **[Components](/reference/components)** — component nào exported,
  prop nào, slot nào, override như thế nào.
- **[CSS Tokens](/reference/css-tokens)** — Tailwind color, spacing,
  shadow, font token với giá trị + use case.

## Convention

Mỗi reference page tuân theo cấu trúc:

1. **Summary** — một đoạn ngắn nói cái này là gì.
2. **Field/Prop table** — bảng `name | type | default | note`.
3. **Examples** — snippet copy-paste được.

Không có "how to" — chuyển qua [Guides](/guides) cho task-oriented
content.
